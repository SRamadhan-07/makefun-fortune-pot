A Python program — standard library only, no network — that writes one line to /output/entry.txt: a kind, funny fortune for a houseplant, promising that a tall stranger will move it six inches toward the light and all that leaning will finally make sense. The line sits inside the competition's gate of 1 to 120 characters of UTF-8 text, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
